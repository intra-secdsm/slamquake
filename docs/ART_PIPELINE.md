# Art Pipeline

Every 3D asset is generated by Python scripts running inside Blender, with no hand modelling.
Godot loads the exported `.glb` files from `game/assets/generated/`.

```bash
tools/build_assets.sh                 # all targets, full quality (~15 s)
tools/build_assets.sh wrestler --quick  # coarse mesh for fast iteration (~3 s)
tools/screenshot.sh res://match/showcase.tscn /tmp/shot.png 30 --cam=face
```

`build_assets.sh` runs each target in a fresh Blender process with a fixed hash seed. It
only replaces a `.glb` when the content really changed (see `glb_equivalent` in
`blender/wrestle_gen/util.py`), so regenerating doesn't churn Git LFS.

## Layout

| File | What it does |
|---|---|
| `blender/build.py` | Entry point; targets `wrestler`, `ring` |
| `wrestle_gen/rig.py` | The shared 26-bone humanoid rig (A-pose, metres, feet at z=0) |
| `wrestle_gen/sdf.py` | numpy signed-distance primitives, smooth blends, surface-nets meshing |
| `wrestle_gen/body.py` | Body, hair styles and eyes; skin weights; blend shapes; shader data |
| `wrestle_gen/poses.py` | Readable pose authoring and baking poses into Blender actions |
| `wrestle_gen/anims/*.py` | The animation library (each module exports `ALL`) |
| `wrestle_gen/ring.py` | Ring, steps, floor mats, barricade (sizes from `game/data/ring_spec.json`) |

## Characters

The body is one signed-distance shape built from about 80 bone-tagged primitives (ellipsoids
and tapered capsules), blended with smooth unions. The pipeline:

1. Mesh it with surface nets on an 8 mm grid, decimate to about 26k triangles, and
   snap the vertices back onto the surface.
2. **Skin weights** come from the same primitives. Each bone's weight falls off with that
   bone's distance to the vertex, so weights blend exactly where the shapes blend.
3. **Blend shapes** (`heavy`, `slim`, `muscle`, `gut`, `kneepads`) come from projecting the
   base mesh onto variant shapes. Every variant shares the topology, so create-a-wrestler
   can mix them freely.
4. **Shader data:** attire isn't modelled. `game/fx/wrestler_body.gdshader` paints trunks,
   boots, kneepads, wristbands, eyebrows and mouth from per-vertex rest-pose data:
   - `UV0`: rest position x and z
   - `UV1`: position along the limb, and depth
   - `COLOR`: arm/leg/head/torso region weights

   Because of this, attire colors and lengths are just `WrestlerLook` parameters.

Hair styles are separate SDF meshes (`hair_<style>`), skinned 100% to `head`. Eyes are
spheres whose vertex color holds the angle from the gaze axis. The eye shader draws
the iris and pupil from that angle.

## Animation

Poses use anatomy-like terms, defined in rest space so they don't depend on bone roll:

```python
STANCE = merge(GUARD_ARMS, sym({
    "thigh.L": {"raise": 20, "spread": 7, "twist": 8},
    "shin.L": {"bend": 32},
}), {"spine": {"bend": 7}})

idle = Anim("idle", [(0.0, STANCE), (0.9, add(STANCE, BREATHE_IN)), (1.8, STANCE)], loop=True)
```

| Bones | Semantics (degrees) |
|---|---|
| hips, spine, chest, neck, head | `bend` forward, `lean` to own left, `turn` to own left |
| clavicle | `shrug`, `reach` |
| upper_arm | `raise`, `swing` (forward), `twist` |
| forearm | `bend` (elbow), `twist` |
| hand / fingers / thumb | `bend`, `tilt` / `curl` |
| thigh | `raise` (forward), `spread`, `twist` (toes out) |
| shin / foot / toe | `bend` (knee) / `flex` (toes up) |

`hips` and `root` also take `move=(left, forward, up)` in metres.

Other details:
- `sym()` copies `.L` values to `.R`, and `mirror()` swaps sides for a left-handed version of a move.
- With `ground=True` (the default), each key is shifted so the lowest boot sole touches the floor.
- Animations export as in-place clips. The loop flag, length and event times (for example
  `hit`) go to `game/assets/generated/wrestler.json`, which `WrestlerModel` reads.

To add moves, add a module under `anims/`, append it to `anims/__init__.py`, rebuild, then
check poses with `--anim=<name> --anim_time=<t>` on the showcase screenshot.
